# V2 Phase 6D -- Publication Figures and Diagrams Index

IEEE-style figures (`scripts/paper_style.py`; fixed Okabe-Ito per-arm colors
PPO `#D55E00` / HPA CPU+memory `#0072B2` / HPA CPU-only `#009E73`, each with

diagrams (`dot`). Every figure/diagram below is PDF (vector) + PNG (300 dpi);

`scripts/generate_v2_phase6d_figures.py` (plots) and the `.dot` sources in
this directory (diagrams). Supersedes the Phase 6C draft set, archived at
`docs/archive/figures_6c_draft/`.
