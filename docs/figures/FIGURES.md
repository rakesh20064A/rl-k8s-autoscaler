## Notes on what changed from Phase 6C

- All 13 plots/diagrams above (P0-P8, D1-D4) are rendered by
  `scripts/generate_v2_phase6d_figures.py` and the `.dot` sources in this
  directory, styled via `scripts/paper_style.py` (IEEE sizing, fixed
  Okabe-Ito palette, no in-figure titles, PDF+300dpi PNG).
- The Phase 6C figure/diagram set (`training_*`, `eval_final_*` with its old
  naming, `stress_explore_*`, `ppo_*`, `diagram_*` under the old style) is
  archived unchanged at `docs/archive/figures_6c_draft/` for reference, not
  deleted.
- `docs/archive/figures_v1/` was created for any V1-era image, but none was
  found under `docs/` -- it is empty.
- **Canonical arm labels** (this phase's item 7): every figure legend,
  diagram label, and table `arm` value now uses "PPO (multi-metric, 11
  signals)" / "HPA CPU+Memory (resource baseline)" / "HPA CPU-only
  (Kubernetes default)" in place of the shorter Phase 6C labels, defined
  once in `scripts/paper_style.py`'s `ARM_LABELS` (all figures) and applied
  to the 3 existing table sets by relabelling their `arm` column values in
  place (same numbers, same file paths, only the label text changed).
  `P0`/`T1`-`T4` are new additions built with the canonical labels from the
  start. The 4 Graphviz diagrams label architecture components (e.g. "PPO
  policy", "PPO agent", "HPA") rather than doing a 3-way arm comparison, so
  they were left as-is -- there is no arm-identity label in them to update.
